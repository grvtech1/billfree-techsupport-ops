Popup Not Appearing / Delayed
BillFree process may be stuck or POS using wrong printer
Quick Fix
Run BillFree Reset when no popup + no print, or when only popup is slow. Double-click the BillFree Reset icon and do a test print.
What to Ask
Ask if any print is coming · Ask if popup is slow or completely absent
Non-Tech Script
"Sir/Ma'am, ek baar BillFree Reset icon ko double-click karke test print kar dijiye."
Deep Tech Note
If print is coming but popup is absent → wrong printer likely selected in POS settings.
If only popup is slow → process buildup is likely, BillFree Reset clears the queue.
Bill Not Delivering
Digital delivery needs internet; SMS may mean server-side ok
Quick Fix
Check internet connection. If SMS is received by customer, explain that WhatsApp delivery may have a slight delay — ask them to wait 2-3 minutes.
What to Ask
Ask if PC internet is working · Ask if SMS reached the customer
Non-Tech Script
"Internet check kar lijiye; agar SMS aa gaya hai toh WhatsApp thoda delay ho sakta hai."
Deep Tech Note
No SMS + no WhatsApp with internet working = real delivery failure → create a ticket.
SMS received = server processed it; WhatsApp delay is provider-side, not BillFree.
Print Not Coming
BillFree process stuck or printer config mismatch
Quick Fix
If no popup and no print → run BillFree Reset first.
If popup appears but no print → likely a printer config change in POS settings.
What to Ask
Ask if the popup appears on screen · Ask if the printer was changed recently
Non-Tech Script
"Ek baar dekhte hain popup aa raha hai ya nahi; usse exact path clear ho jayega."
Deep Tech Note
Popup yes + no print = BillFree is working fine, but the physical printer mapping changed in the POS software. This needs POS-side printer reconfiguration.
BillFree Not Working / Service Down
Start with identifying the exact issue type
Quick Fix
First identify: Is it a popup issue, a delivery issue, or a print issue? Each has a different fix — check the cards above.
Non-Tech Script
"Sir, exact issue samajhne ke liye ek quick check karte hain — BillFree popup issue hai, delivery issue hai, ya print issue hai?"
